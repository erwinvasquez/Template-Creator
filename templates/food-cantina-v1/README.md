# Cantina Roja (`food-cantina-v1`)

Template e-commerce plug & play para **cantina mexicana**: tacos, salsas picantes, bebidas y merch.

- **Slug lab:** `/t/cantina`
- **Categoría:** `ecommerce-food`
- **Shop:** `/tienda` · nav «Tienda»
- **About:** `/historia`
- **Sales mode:** solo stock (listo para llevar)
- **Identidad:** Oswald + Karla, rojo y teal, lanes horizontales con scroll

## Home

`hero` → `lanes` → `salsaBar` → `mercado` → `fiesta` → `merch`

## Uso SaaS

```ts
import { TemplateApp, commerceViews, TEMPLATE_ID } from "@web-generator/food-cantina-v1/client";
```

Validación: `npm run template:validate -- food-cantina-v1`
